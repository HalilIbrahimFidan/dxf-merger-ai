# dxf-merger-ai
A web-based tool to automatically merge, arrange, and measure 2D DXF drawings from SolidWorks. Built with AI/Vibecoding.

📐 DXF Smart Merger & Measurer
A streamlined, web-based tool designed for mechanical engineers, designers, and CNC/Laser cutting operators. It allows you to upload multiple 2D DXF files (e.g., exported from SolidWorks), automatically calculates their bounding box dimensions (Width x Height), writes the file name and dimensions on the drawings, and merges them into a single layout file for easy nesting.

🚀 Features
 Batch Processing: Upload multiple DXF files at once.
 Auto-Measurement: Automatically calculates the Width and Height of each part.
 Smart Labeling: Adds the file name and dimensions directly onto the drawing.
 Nesting Layout: Arranges all individual parts side-by-side with appropriate margins.
 Single Export: Merges everything into a single ⁠Merged_Drawings.dxf⁠ file for quick downloading.

🤖 Built with Vibecoding
This project was entirely conceptualized and generated using AI (Vibecoding). It demonstrates how natural language prompts can quickly turn workflow automation ideas into fully functional web applications.
🛠️ Tech Stack
 Python - Streamlit (For the web interface)
 ezdxf (For parsing and merging DXF files)
 Pandas (For displaying results data)
